# 記録音

Mac の再生音とマイクを、別々の字幕としてその場で文字にするアプリ。文字と音声は自分の Mac に残る。相手が複数人いても、ラベルは「相手」と「自分」だけ。

2026-10-27 時点のソースに合わせて書いた。作り方の調査は [research.md](research.md)。

- 表示名: 記録音
- 実行ファイル: LocalTranscription
- バンドル ID: `app.local.transcription`
- バージョン: 0.1
- 動作条件: macOS 26、Apple Silicon（`build.sh` のターゲットは `arm64-apple-macos26.0`）
- インストール先: `~/Applications/記録音.app`

## 録音で起きること

開始すると、メインディスプレイの再生音とマイクを同時に取り込む。再生音は「相手」、マイクは「自分」。途中経過は画面上部の2行に出て、文が確定すると上に積まれ、ファイルにも書かれる。

映像の出力は付けていない。ストリーム側のサイズは 2×2ピクセル、間隔は1秒、カーソルなし。保存するのはテキストと wav だけ。

Teams や Meet には絞っていない。そのディスプレイで鳴っている音は、どのアプリのものでも「相手」に入る。このアプリ自身の音は除く。

ヘッドホンを付ける前提。スピーカーだと相手の声がマイクに入り、「自分」の行にも出る。エコーキャンセルは入れていない。画面下にも同じ注意がある。

既定では2時間でファイルを区切り、録音自体は続ける。区切って残した方には、その場では名前を付けない。停止したときだけ名前を聞く。このアプリが前面のときだけその場で出し、ほかのアプリが前面のときはタイムスタンプのまま保存して、戻ったときに聞く。そのダイアログは、保存せずに消して閉じることもできる。文字と wav は録音中から書いてあり、名前はフォルダ名と transcript の先頭に足すだけ。空欄でもよく、あとから一覧で変えられる。区切りの秒数は環境変数 `SESSION_MAX_SECONDS`（1以上）で変えられる。

自分の字幕が、渡した音声より2秒以上遅れると、マイクの変換を間引きに切り替え、状態欄にその旨が出る。

確定した文は、頻出ワードの設定にしたがって言葉に直してから表示・保存する。メニューの「頻出ワード」で、言葉と、誤って出る表記を書く。区切りは読点、カンマ、改行。長い表記を先に見て、同じ表記が複数の言葉にあるときは一覧の上を使う。途中の字幕にはかけない。

設定は `~/Library/Application Support/LocalTranscription/frequent-words.json`。ファイルが無い初回だけ、次の1件を書く。すでにあるファイルは変えず、読めないファイルは上書きしない。読めないときは変換しない。

| 言葉 | 誤って出る表記 |
|---|---|
| Notion | ノーション |

## 取り込みと認識

音は ScreenCaptureKit。`capturesAudio` で再生音、`captureMicrophone` でマイク。権限はマイクと画面収録の2つ。Core Audio の Process Tap は使っていない。

文字起こしは、相手用と自分用で別々の `SpeechTranscriber`（SpeechAnalyzer）。ロケールは日本語。途中結果と確定結果の両方を受け取る。日本語の認識モデルが無ければ、開始時にダウンロードする。アプリ自身が通信するのは、このダウンロードだけ。

認識に渡す形式は、16 kHz・モノラル・Float32・非インターリーブを優先する。その形式で取り込みを開始できなければ、48 kHz・モノラルで取り込み直してから変換する。

## 保存先

`~/Library/Application Support/LocalTranscription/sessions/`

フォルダ名は `yyyyMMdd-HHmmss`。名前を付けると `yyyyMMdd-HHmmss 題名` になる。題名は60文字までで、`/` `:` `\` と制御文字は空白に潰れる。同じ名前があるときは末尾に番号を付ける。

フォルダの中身は次の3つ。

- `transcript.txt`
- `audio-system.wav`（相手）
- `audio-mic.wav`（自分）

`transcript.txt` の形:

```text
# 題 企画定例
# 2026-10-27 15:31:04
# 16000 Hz モノラル
[15:31:10] 自分 はい
[15:31:12] 相手 今週の定例です
```

`# 題` の行は、名前を付けたときだけある。時刻は確定したときの時計で、音声内の位置ではない。

## 操作

- 開始と停止。ショートカットは ⌘⇧R。メニューの「録音の開始と停止」も同じ
- 停止すると名前を聞く。このアプリが前面のときだけその場で出す。ほかのアプリが前面のときは保存したままにし、戻ったときに聞く。状態欄にその旨が出る。「保存しない」か Esc で、その録音を消してダイアログを閉じる
- 録音中の「リセット」（メニューの「録音をリセット」も同じ）で、途中までを空にする。保存して残すか、消すかを選ぶ。キャンセルすると録音は続く。選んだあとは録音が止まり、画面の文字は空になる
- 「フォルダ」で、いまのセッションを Finder で開く
- マイクか画面収録が拒否されているときは、そのボタンが「設定」になり、該当するシステム設定を開く
- 「記録」でこれまでの一覧。列は日時、名前、最初の「相手」の行。録音中のものは名前を変えられない
- 「頻出ワード」で、言葉と誤って出る表記を編集する
- 録音中にウィンドウを閉じると、止めて終了するか聞く。止めたあとの名前のダイアログで、保存するか消すかを選ぶ。名前をまだ聞いていないときに閉じた場合も、先にそのダイアログを出す
- ウィンドウはほかのスペースや、フルスクリーンのアプリの上にも出る

## ビルド

初回だけ `./scripts/make-signing-identity.sh` で自己署名の Code Signing 証明書を作る。そのあとリポジトリ直下で `./build.sh`。`swiftc` で `dist/LocalTranscription.app` を作り、同じ証明書で署名して `~/Applications/記録音.app` に置き換える。アドホック署名だと、システム設定で画面収録がオンでもアプリ側は未許可のままになる。`dist/` は git に入れない。

`Tests/` には変換、頻出ワード、セッション名、名前を聞くタイミングの確認用プログラムがある。テストランナーには繋がっていない。

## ソース

- `Sources/main.swift` … ウィンドウ、開始と停止、2時間での区切り、記録の一覧、頻出ワード
- `Sources/TitlePrompt.swift` … 停止後に名前を聞くタイミング
- `Sources/Capture.swift` … ScreenCaptureKit
- `Sources/Transcribe.swift` … SpeechTranscriber、モデルの導入、音声形式の選択
- `Sources/Convert.swift` … マイクなどの形式を、認識へ渡す形式へ変換する
- `Sources/SessionStore.swift` … セッションのフォルダ、transcript、wav、名前
- `Sources/FrequentWords.swift` … 頻出ワードの読み書きと、確定文への反映
- `Info.plist` … 表示名、macOS 26、マイクと画面収録の使用目的
- `build.sh`

## 調査メモとの関係

[research.md](research.md) は 2026-10-04 の調査で、当時の第一案は「Core Audio の Process Tap でアプリ単位に録り、会議後に高精度のモデルで清書する」だった。実装は次の点で違う。

| 調査の第一案 | いまの実装 |
|---|---|
| Core Audio Process Tap で Teams や Meet だけを録る | ScreenCaptureKit で、メインディスプレイの再生音をまとめて録る |
| マイクは AVAudioEngine | マイクも ScreenCaptureKit |
| 権限は音声収録専用 | マイクと画面収録 |
| 会議後に kotoba-whisper などで清書 | していない。リアルタイムの確定文だけ |
| 相手同士の話者分離は、保存したトラックへ後からかける | wav は残している。分離はかけていない |
| 先に meeting-transcriber で確かめる | [meeting-transcriber-eval.md](meeting-transcriber-eval.md) の結果欄は空欄 |

[note.md](note.md) と [x-post.md](x-post.md) は、その調査の材料。このアプリの説明ではない。
